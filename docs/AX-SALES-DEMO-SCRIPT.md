# AX Sales Demo Script

Cadence 17 visual intelligence. Fictional enterprises. Configured demo coverage. Not a live operator SLA.

## 30-second opening

NetAware connects enterprise demand to network supply.

An application expresses a business Intent. NetAware discovers which network capabilities matter, whether they are permitted and available, and how to fulfill them through operators or aggregators. It returns a business outcome.

## Enterprise 3-minute

Path: Welcome → Enterprise → Start meeting → 3-minute executive.

1. Rocket Bank wants to verify a customer's mobile number. The application does not ask for NV1, NV2, or an API name.
2. Run the Intent. Cellular → NV1. Wi-Fi → NV2. Wi-Fi + operator readiness gap → cannot fulfill that path.
3. Close: one business Intent, different network conditions, NetAware selects the feasible path.

## Operator 3-minute

Path: Operator → Start meeting → 3-minute executive.

1. Number Verification demand. API available is not the same as Intent fulfillable.
2. Provider A: NV API, NV1, NV2, ECS ready. Provider B: NV API, NV2, ECS not ready. Wi-Fi demand blocked.
3. Close: API exposure is only one part of enterprise fulfillment.

Optional: Acme OTA Provider C roaming gap. 500 simulated devices. Qualified-demand gap, not lost revenue.

## Aggregator 3-minute

Path: Aggregator → Start meeting → 3-minute executive.

1. Enterprise Intent needs a consistent outcome. Supply is fragmented by operator, region, and route.
2. Canada / Germany / Singapore. Aggregator A: routed through / normalized through / available via. Does not own operator APIs.
3. Close: fragmented supply becomes consistent fulfillment.
